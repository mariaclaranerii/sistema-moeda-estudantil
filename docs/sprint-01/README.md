# Lab03S01 - Modelagem do sistema

## Objetivo da sprint

Produzir a modelagem inicial do Sistema de Moeda Estudantil, coerente com o enunciado completo e preparada para orientar uma futura implementação Java em arquitetura MVC.

## Critérios adotados

- Requisitos e regras de negócio recebem identificadores estáveis em `../requisitos.md`.
- Decisões não explícitas no PDF ficam registradas em `../premissas-de-modelagem.md`.
- `../rastreabilidade.md` liga requisitos, histórias e elementos UML.
